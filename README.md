# vws-github-hands-on

VWSオンライン勉強会 #50「AI時代に最低限知っておきたいGitHub入門」のハンズオン用リポジトリです。

架空のカフェ「VWS CAFE」の1ページサイトを題材に、GitHubの基本的な使い方を体験します。

## このリポジトリの中身

| ファイル | 内容 |
| --- | --- |
| `index.html` | カフェサイトのページ本体 |
| `style.css` | 見た目の設定。先頭の色の指定を変えるとサイト全体の色が変わります |
| `.gitignore` | Gitで管理しないファイルの指定 |

## 自分で試してみる

1. 自分のアカウントを選び、好きなリポジトリ名を付けて作成
2. できあがったリポジトリで、自由に編集・Commitしてみてください

※ このリポジトリ自体は書き換えできませんが、**Issue は誰でも作成できます**。

## 今日やること

1. **Repository / Commit** — ファイルを変更して、変更履歴が残るのを確認する
2. **Branch / Pull Request / Merge** — 別のBranchで変更し、内容を確認してから反映する
3. **Issue** — やることを登録し、Issue → 修正 → Pull Request → Merge の流れを体験する

## 練習のお題

- キャッチコピー（`index.html` の `hero-text`）を書き換える
- メニューを1つ追加する／値段を変える
- `style.css` の `--main-color` を好きな色に変える
- 「お知らせ」セクションを新しく追加する
- 定休日を変更する
